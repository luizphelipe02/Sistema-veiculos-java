# 🚗 Sistema de Veículos - Java

Sistema de gerenciamento de veículos desenvolvido em Java puro, 
como parte do meu aprendizado em desenvolvimento back-end.

## 📋 Funcionalidades

- ✅ Cadastrar veículo
- ✅ Listar veículos
- ✅ Adicionar turbo
- ✅ Remover veículo

## 🛠️ Tecnologias utilizadas

- Java
- Orientação a Objetos (Herança e Encapsulamento)
- ArrayList
- Tratamento de Exceções

## 🚀 Como rodar o projeto

1. Clone o repositório
   git clone https://github.com/luizphelipe02/Sistema-veiculos-java.git
2. Abra no IntelliJ IDEA
3. Execute a classe `main.java`

## 📚 Conceitos aplicados

- Herança com classe abstrata `Veiculo`
- Encapsulamento com getters e setters
- ArrayList para gerenciamento em memória
- Tratamento de exceções com try-catch
- Separação de responsabilidades (domain, service)
